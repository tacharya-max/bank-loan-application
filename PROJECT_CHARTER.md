# Project Charter – Bank Loan Application

## 1. Domain Name
Bank Loan Application Management System.

## 2. Problem Statement
This system will help banks manage customer loan applications in one place. Bank employees can easily access customer details and loan information.

## 3. Main Things to Manage
1. Customer Details
2. Loan Applications
3. Loan Types
4. Loan Documents
5. Loan Amount
6. Application Status

## 4. Open Question
Should loan eligibility be checked automatically by the system or manually by bank employees?
